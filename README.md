# Age Verification Application

A simple and interactive **Python** script that serves as a gatekeeper app, verifying whether a user is old enough to access the application based on their age input.

## Features
- **Age Restriction:** Dynamically checks if the user is 12 years old or older.
- **Conditional Logic:** Uses `if-else` statements to route users to the appropriate response.
- **Interactive Console Input:** Prompts the user with a clean interface and delivers immediate feedback.

## Technologies Used
- Python 3
